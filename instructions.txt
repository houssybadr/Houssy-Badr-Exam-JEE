### 4. Séquence Auth JWT (04-sequence-auth-jwt.puml)
```plantuml
@startuml SequenceAuthJWT
!theme plain
actor User
participant "Frontend\n(Angular/Thymeleaf)" as Front
participant "/auth/login" as Auth
participant "SecurityFilter" as Sec
participant "UserDetailsService" as Svc
database "Base de Données" as DB

User -> Front : Saisit credentials
Front -> Auth : POST {username, password}
Auth -> Svc : authenticate()
Svc -> DB : findByUsername()
DB --> Svc : User + Roles
Svc --> Auth : UserDetails
Auth -> Auth : génère JWT (HMAC SHA256)
Auth --> Front : {accessToken, refreshToken}
Front -> Front : stocke tokens

note over User, DB : Requêtes suivantes authentifiées

Front -> Sec : GET /api/resource\nHeader: Bearer {token}
Sec -> Sec : valide JWT + extrait rôles
Sec --> Front : 200 OK + data

@enduml
```
